# v1.3.0 测试报告

## 修复的直接原因

1. `main.js` 只监听 `DOMContentLoaded`。动态 module 加载较晚时，该事件已经结束，因此阶段、结束回合、详情关闭等事件没有绑定。
2. 手牌第一次单击会立刻打开详情，导致依赖双击的出牌操作无法可靠触发。
3. AI 在一个同步循环中瞬间完成整回合，用户看不到其出牌过程；需要目标的魔法也没有统一选择目标。

## 实际执行

- `npm run check`：JavaScript 语法检查通过。
- `npm test`：142 项通过，0 项失败。
- `npm run selftest`：20 局 BOT 对战全部正常结束。
- Chromium DOM 交互测试：
  - 5 张手牌正常显示；
  - 单击卡牌打开操作面板；
  - “攻击表示召唤”按钮触发召唤；
  - 拖动怪兽到己方区域触发召唤；
  - 魔法卡“发动魔法”触发；
  - 详情右上角 × 可以关闭；
  - 浏览器页面错误为 0。

## 说明

运行环境禁止 Chromium 直接访问 localhost，因此浏览器测试使用同一份 HTML、CSS 和 `GameUI` 源码注入测试页面完成。完整回合和 AI 行动则使用真实 `GameState`、`GameEngine` 与 `GameController` 自动测试。
