# v1.2.0 战斗修复说明

截图中的问题属于 UI 半渲染：游戏状态已经开局，因此 HUD 显示牌库和手牌数量；但手牌区域渲染中断，导致阶段、按钮和卡牌没有继续更新。

本版处理：

1. 阶段、按钮和 HUD 独立安全渲染。
2. 单张卡面异常只显示后备卡面，不会中断整场决斗。
3. 底部新增固定手牌托盘。
4. 双方新增实体牌库卡堆与实时数量。
5. 对手手牌显示卡背。
6. 拖放出牌与拖放攻击经过浏览器 DOM 冒烟检查。
7. 修复 AI 多次通常召唤导致的潜在无限循环。
8. 启动脚本会关闭占用 8080 的旧服务器，避免打开旧缓存版本。

操作：

- 怪兽拖到己方怪兽区：召唤。
- 按住 Shift 拖怪兽：守备表示。
- 魔法/陷阱拖到己方魔法陷阱区：发动或盖放。
- 战斗阶段把己方怪兽拖到敌方怪兽：攻击。
- 对方无怪兽时，把怪兽拖到对手头像：直接攻击。
- 单击卡牌：详情；双击：备用快速出牌。
