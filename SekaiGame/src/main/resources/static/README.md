# Nightcord Duel Network v1.4.0

使用原生 HTML、CSS 和 JavaScript ES Module 制作的本地数字卡牌游戏。当前版本已经接通游戏大厅、卡包商店、收藏、卡组编辑、AI 对战、奖励和本地存档，并将决斗规则改为接近传统《游戏王》流程的自动阶段模式。

## 在 IDEA 中运行

1. 解压项目。
2. 在 IntelliJ IDEA 中选择 **Open**，打开项目根目录。
3. 在 IDEA Terminal 执行：

```bash
npm start
```

也可以在 Windows 中双击：

```text
start.bat
```

浏览器访问：

```text
http://127.0.0.1:8080
```

项目使用 ES Module，不能直接双击 `index.html`。更新版本后建议按一次 `Ctrl + F5`。

## 当前决斗规则

- 双方初始 **8000 LP**。
- 双方起手各抽 **5 张**。
- 猜拳决定先后手；获胜者可以选择先攻或后攻。
- 先攻第一回合不抽卡，也不能攻击。
- 后续每个回合自动抽 1 张。
- 卡组无牌可抽时直接落败。
- 主卡组 **40～60 张**，同名卡最多 3 张。
- 1～4 星怪兽无需祭品；5～6 星需要 1 只祭品；7 星及以上需要 2 只祭品。
- 每回合只能进行 1 次通常召唤，特殊召唤次数由卡牌效果决定。
- 攻击表示怪兽在召唤当回合即可攻击；先攻第一回合除外。
- 陷阱盖放当回合不能发动，经过一次回合交换后才可触发。
- 结束阶段手牌超过 6 张时，必须选择丢弃至 6 张。
- 引擎支持由卡牌数据声明“五件套”特殊胜利条件；当前 Nightcord 卡池尚未加入对应五张卡。

### 战斗结算

- 攻击表示对攻击表示：比较 ATK，较低怪兽被破坏，差额扣除其控制者 LP；相同则双方破坏。
- 攻击表示对守备表示：ATK 高于 DEF 时守备怪兽被破坏，但默认不扣 LP；只有具有贯穿效果时才扣差额。
- ATK 等于 DEF 时双方不破坏、不扣 LP。
- ATK 低于 DEF 时攻击方扣除差额 LP。
- 对方场上没有怪兽时可以直接攻击玩家。

## 阶段自动推进

玩家不需要手动点击“抽卡阶段、准备阶段、主要阶段、战斗阶段”等按钮。

```text
回合开始
  → 自动抽卡（先攻第一回合跳过）
  → 自动准备阶段
  → 主要阶段1
  → 点击可攻击怪兽时自动进入战斗阶段
  → 战斗后再次使用手牌时自动进入主要阶段2
  → 点击结束回合
  → 自动处理结束阶段并交换回合
```

右下角只有一个主要按钮：

```text
结束回合
```

## 操作方法

### 手牌

- **单击手牌**：打开操作菜单。
- 怪兽卡可以选择“攻击表示召唤”或“里侧守备盖放”。
- 魔法卡可以选择发动或盖放。
- 陷阱卡可以选择盖放。
- **拖动怪兽到己方怪兽区**：攻击表示召唤。
- **按住 Shift 拖动怪兽到己方怪兽区**：里侧守备盖放。
- **拖动魔法/陷阱到己方魔法陷阱区**：发动或盖放。

### 攻击

- 可以攻击的怪兽会显示“可攻击”标记。
- 单击该怪兽会自动进入战斗阶段。
- 再单击敌方怪兽完成攻击。
- 对方没有怪兽时，单击敌方玩家信息区进行直接攻击。
- 也支持把己方怪兽拖到敌方怪兽或敌方头像。

### 详情

- 右键卡牌打开完整详情。
- 可以通过右上角 `×`、底部“关闭详情”、点击背景或按 `Esc` 关闭。

## AI 回合

AI 会分步执行：

```text
抽卡
→ 主要阶段出牌
→ 通常召唤或盖放
→ 发动可用魔法
→ 战斗阶段选择目标攻击
→ 主要阶段2
→ 结束阶段丢弃超额手牌
→ 结束回合
```

AI 不会再瞬间跳过整个回合。

## 完整产品流程

```text
游戏大厅
→ 使用决斗币抽取 Nightcord 卡包
→ 卡牌和插画进入收藏
→ 在卡组编辑器中组建 40～60 张合法卡组
→ 使用当前卡组挑战 AI
→ 对局结束获得决斗币
→ 继续抽卡并调整卡组
```

- 已实现主卡组 40～60 张的实际构筑和战斗。

- 尚未实现完整连锁、优先权和所有官方卡牌时点规则。
- 项目中的人物插画只适合课堂和个人演示；公开发布或商业使用前应确认素材授权。
